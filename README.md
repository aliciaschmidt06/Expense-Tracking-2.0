# Expense-Tracking-2.0

Expense-Tracking-2.0 is a small self-hosted containerized Rails application to help you import, categorize, and analyze personal transaction data. It provides CSV import with duplicate review, an insights dashboard (income vs spending, subscriptions, top expenses), and a simple category/keyword system that can auto-assign transactions.


## Run the app 

0. Open a terminal 
1. git clone repo
2. `cd Expense-Tracking-2.0`
3. `./run.sh`

Then follow the apps prompts to your browser 🚀
